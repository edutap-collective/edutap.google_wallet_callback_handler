# eduTAP.google_callback_handler - A Callback-Handler for Google Wallet

This eduTAP Package provides you with a reusable callback handler that conforms with the API specification from Google Wallet.

## Usage as Library

This package is intended to be used as a Library within other larger systems.
Therefore we provide setups for different web frameworks and storage backends.

Recommended is to use the fastAPI and Apache Kafka variant.
